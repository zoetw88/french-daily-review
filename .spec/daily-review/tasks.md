# Daily French Review UI

## Acceptance criteria

- [x] Uses the learner's class topics and recurring mistakes.
- [x] Presents a clear daily study plan with visible progress.
- [x] Supports interactive recall, answer reveal, confidence grading, and next question.
- [x] Saves progress and streak state locally in the browser.
- [x] Includes a browsable class schedule and mistake notebook.
- [x] Responsive on desktop and mobile.
- [x] Verified in a real browser at desktop and mobile widths.

## Adaptive review upgrade

- [x] Require an active typed answer before revealing the model answer.
- [x] Compare the response and show a similarity score plus a targeted hint.
- [x] Persist per-card review history, accuracy, streak, and next review date.
- [x] Schedule cards at 10 minutes, 1 day, or expanding 3/7/14/30-day intervals.
- [x] Prioritize due and frequently missed cards in the daily session.
- [x] Show due, mastered, and weak-card metrics.
- [x] Show mistake totals by learning category.
- [x] Add the 2026-07-22 passé composé lesson.
- [x] Show the learner's TCF Canada B2 goal and dated level milestones without fabricating exam scores.
- [x] Verify the upgraded answer and scheduling flow in a real browser.
