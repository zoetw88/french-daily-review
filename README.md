# French Daily Review

A personal French-learning workspace for daily review, class notes, and reusable study materials.

## What is here

- Daily French review materials
- Course notes and lesson references
- Study PDFs and presentation decks
- Learning documents organized by topic
- Project notes and review workflow

## Repository map

- `french-daily-review/` — daily review content
- `法語/` — French learning materials
- `上課筆記/` — class notes
- `教材PDF/` — reference PDFs
- `課件PPTX/` — lesson slide decks
- `.spec/` — project planning and working notes
- `docs/` — supporting documentation

## Suggested workflow

1. Add new materials to the matching topic folder.
2. Keep original files unchanged when possible.
3. Put personal summaries and review notes in `french-daily-review/`.
4. Use clear filenames with the date or lesson number.
5. Keep private personal information out of public files.

## Status

This is a personal, local-first study repository. It is organized for quick daily review rather than public software distribution.
