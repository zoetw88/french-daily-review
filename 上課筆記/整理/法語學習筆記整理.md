### 文法:動詞 porter(穿)變位
| 主詞 | 變位 |
|---|---|
| je | porte |
| tu | portes |
| il / elle | porte |
| nous | portons |
| vous | portez |
| ils / elles | portent |

> 規則:第一組 -er 動詞,`...ent` 結尾發音同 `e`(不發音)。

### 文法:avoir(有)變位
| 主詞 | 變位 |
|---|---|
| j' | ai |
| tu | as |
| il / elle | a |
| nous | avons |
| vous | avez |
| ils / elles | ont |

### 文法:否定句 La forme négative
- 結構:**ne + 動詞 + pas**
- **重點**:否定句中 un / une / des → **de**
  - Je porte une chemise → Je ne porte pas **de** chemise
- **重點**:動詞以母音開頭時,ne → **n'**(n' + a, e, i, o, u)
  - Je n'ai pas de blouson
  - Vous n'avez pas de baskets
  - Ils n'ont pas de chemises blanches

### 文法:複數 Le pluriel
- le, la → **les**
- un, une → **des**
- 名詞 + **s**
  - Je porte une chemise → Je porte **des** chemises

### 文法:疑問形容詞 quel(什麼 / 哪一個)
| 形式 | 用法 |
|---|---|
| quel | 陽性單數 |
| quelle | 陰性單數 |
| quels | 陽性複數 |
| quelles | 陰性複數 |
- quelle est la couleur de la robe?(這件洋裝什麼顏色?)
- il y a quelles couleurs?(有哪些顏色?)
- combien coûte la robe?(這件洋裝多少錢?)

### 文法:指示形容詞 ce(這 this)
| 形式 | 用法 |
|---|---|
| ce | 陽性名詞 |
| cette | 陰性名詞 |
| ces | 複數 |
| cet | 母音或啞音 h 開頭之前(a, o, i, h muet) |

## 貫穿全期的重點文法總表

1. **-er 動詞變位**:-e / -es / -e / -ons / -ez / -ent(如 porter, aimer, trouver)。
2. **否定句**:ne + 動詞 + pas;母音前 ne → n';否定後冠詞 un/une/des → de。
3. **複數**:le/la → les;un/une → des;名詞 + s。
4. **疑問形容詞 quel**:quel / quelle / quels / quelles(隨後面名詞的陰陽性數變化)。
5. **指示形容詞 ce**:ce(陽) / cette(陰) / ces(複) / cet(母音前)。
6. **反身動詞**:me / te / se / nous / vous / se + 動詞;母音前 me → m'。
7. **不規則動詞**:avoir、faire、lire、écrire、aller。
