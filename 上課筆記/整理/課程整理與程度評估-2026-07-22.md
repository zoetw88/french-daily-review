# 2026-07-22 課程整理與程度評估

## 課程

- 主題：**Il est comment ?**
- 教材單元：Leçon 18
- 核心情境：描述昨天做過的事、購物、用餐與一週行程

## 本課重點

### Passé composé（複合過去式）

本課先使用 `avoir` 作助動詞：

```text
主詞 + avoir 現在式 + participe passé
```

| 主詞 | avoir | 範例 |
|---|---|---|
| je | ai | j'ai acheté |
| tu | as | tu as téléphoné |
| il / elle | a | elle a regardé |
| nous | avons | nous avons mangé |
| vous | avez | vous avez écouté |
| ils / elles | ont | ils ont joué |

### 過去分詞

- `-er → -é`：acheter → acheté、travailler → travaillé
- `-ir → -i`：finir → fini
- 不規則：
  - faire → fait
  - boire → bu
  - prendre → pris
  - lire → lu
  - voir → vu
  - écrire → écrit
  - comprendre → compris
  - répondre → répondu
  - être → été
  - avoir → eu

### 否定式

```text
主詞 + ne / n' + 助動詞 + pas + 過去分詞
```

- Il **n'a pas mangé** de poisson.
- Sa sœur **n'a pas pris** de viande.
- Ils **n'ont pas pris** de dessert.

`pas` 要放在助動詞後，不能說 `n'a pris pas`。

### 過去時間敘事

- hier：昨天
- hier midi：昨天中午
- hier soir：昨天晚上
- d'abord：首先
- ensuite：接著
- et après：然後

## 課堂表現

### 已掌握

- 能正確套用大部分 `avoir + 過去分詞`：
  - elle a regardé
  - ils ont joué
  - vous avez préparé
  - tu as téléphoné
- 能用數個句子描述昨天的飲食與活動。
- 能理解 `présent` 與 `passé composé` 的基本差異。
- 能正確產出部分否定句，例如：
  - Fabien et sa sœur n'ont pas dîné dans un restaurant italien.

### 尚未穩定

| 課堂輸出 | 修正 | 問題 |
|---|---|---|
| j'ai travaillu | j'ai travaillé | `-er → -é` |
| vous avez écoutez | vous avez écouté | 過去分詞不能使用不定詞字尾 `-ez` |
| j'ai fit | j'ai fait | `faire → fait` |
| je suis chez moi | j'ai été chez moi / je suis rentré(e) chez moi | 過去敘事仍使用現在式 |
| il a traine pour Lille | il a pris le train pour Lille | 詞彙與固定搭配 |
| Fabien ne a pas mangé | Fabien n'a pas mangé | 母音前使用 `n'` |
| sa sœur n'a pris pas | sa sœur n'a pas pris | `pas` 放在助動詞後 |

聊天紀錄普遍省略重音符號，可能部分來自輸入方式；因此不單獨把重音缺失視為程度判定依據。

## CEFR 程度評估

### 教材／課程內容：A1 後段至 A2 入門（A2.1）

原因：

- 從現在式進入 `passé composé`，開始描述已完成的過去事件。
- 需要串連數個事件並使用 `hier`、`ensuite` 等時間標記。
- 包含常用不規則過去分詞及複合時態的否定式。
- 任務仍以日常活動、購物、用餐和簡短個人敘事為主，尚未達到較複雜的 A2 後段內容。

### 目前可觀察的實際輸出：A1+，正進入 A2

你已具備進入 A2 的結構知識，也能在提示下完成簡短過去敘事；但不規則過去分詞、否定式位置和詞彙提取仍需要老師即時修正。這表示 **A2 內容已開始學習，但主動輸出尚未穩定達到 A2**。

## 升到穩定 A2 的短期標準

1. 不看表格，正確使用 8–10 個常見過去分詞。
2. 能連續說或寫 5 句昨天做過的事。
3. `ne / n' + avoir + pas + participe passé` 的位置正確率達 80%。
4. 能自然使用 `d'abord`、`ensuite`、`puis` 串連事件。
5. 能回答並主動提出 `Qu'est-ce que tu as fait hier ?`
