## PPT: Portrait-robot(Leçon 6 · 服裝顏色 + 否定 · 第2堂 07/04)

## PPT: Shopping(Leçon 7 · 購物描述 · 第3堂 07/06)
**課本文法重點**:
- 疑問形容詞 quel:**quel / quelle / quels / quelles**(隨後面名詞性數)
- 疑問:**Comment** est-ce que tu trouves…? / **Combien** ça coûte?
- 指示形容詞:**ce**(陽) / **cette**(陰) / **ces**(複) / **cet**(母音或 h 前)

**你的錯誤:**

| ❌ 你寫的 | ✅ 正解 | 為什麼 |
|---|---|---|
| **quelle** vetements est-ce que tu **amies**? | **quels** vêtements est-ce que tu **aimes**? | vêtements 陽性複數→quels;動詞 aimes |
| **quels** tu trouves cette table? | **Comment** tu trouves cette table? | 問「覺得如何」用 comment |
| Il y a **comment** couleurs? | Il y a **quelles** couleurs? | 問「哪些顏色」用 quelles |
| **combien** est le prix? | **quel** est le prix? | 問價錢是多少用 quel est le prix |
| **quelles est elle coulers**? | **quelle** est **la couleur** (de la robe)? | 單數陰性 quelle;la couleur |
| **combien est** la robe? | **combien coûte** la robe? | 用動詞 coûter |
| comment est-ce que tu **aime**? | comment est-ce que tu **trouves** ce pantalon? | tu 配 trouves;問感想用 trouver |
| **Ce** robe **es** tres jolie | **Cette** robe **est** très jolie | robe 陰性→cette;est |
| Je trouve **ce** chemise tres jolie | Je trouve **cette** chemise… | chemise 陰性→cette |
| **j'am** bien / **J'am** beaucoup | **j'aime** bien / **J'aime** beaucoup | aimer 拼字 |

## PPT: Le dimanche matin(Leçon 15 · 反身動詞 + 日常 · 第5堂 07/10)
**課本文法重點**:
- 反身動詞:je **me** / tu **te** / il **se** / nous **nous** / vous **vous** / ils **se** + 動詞(母音前 me→m':je **m'habille**)
- faire:je fais / tu fais / il fait / nous faisons / vous faites / ils **font**
- lire:lis/lis/lit/lisons/lisez/**lisent**;écrire:j'**écris**/…/ils **écrivent**

**你的錯誤:**

| ❌ 你寫的 | ✅ 正解 | 為什麼 |
|---|---|---|
| nous nous **leveons** | nous nous **levons** | 拼字 |
| je me **laver** | je me **lave** | 要變位,不能留原形 |
| nous nous **lavon** | nous nous **lavons** | 漏 s |
| ils-**ells** se lavent | ils-**elles** se lavent | elles 拼字 |
| **tu tu** reposes(出現兩次) | **tu te** reposes | 反身代名詞是 te,不是重複 tu |
| **je ecris** | **j'écris** | 母音前 je→j' |
| tu fais **de** tennis | tu fais **du** tennis | faire du + 運動 |
| elle se **leves** | elle se **lève** | 第三人稱單數不加 s |
| Les enfants **ecrit** | Les enfants **écrivent** | les enfants=ils,用複數 |

## PPT: S'entraîner(游泳選手 Laure 的一天 · 時間/作息 · 第6堂 07/16)
**課本主題**:閱讀冠軍 Laure 的作息(elle se lève vers 6 heures / elle s'entraîne / elle se couche vers 22 heures)。

**你的錯誤:**

| ❌ 你寫的 | ✅ 正解 | 為什麼 |

# 常犯錯誤 TOP 9(最該背的規律)

1. **否定的冠詞**:ne…pas 後面 un/une/des → **de**。→ je n'ai pas **de** blouson。(你錯最多次)
2. **縮寫只在母音前**:je/ne/me → j'/n'/m' 只用在 a,e,i,o,u,h 前。子音前不縮:**Nous ne** portons(不是 n'portons)。
3. **反身代名詞別重複主詞**:tu → **te**、il → **se**。tu **te** reposes(不是 tu tu)。
4. **動詞一定要變位**:不能留原形。je me **lave**(不是 je me laver)。
5. **陰陽性一致**:robe / chemise / table 是陰性 → **cette**、**quelle**、jolie、vert**e**。
6. **問句用對詞**:感想=**comment tu trouves**;價錢=**combien ça coûte / quel est le prix**;哪些=**quel(le)(s)**。
7. **il y a ≠ il a**:「有」永遠是 **il y a**。
8. **主詞配對動詞**:je → **ai**(不是 avez);elle → **lève**(不加 s);ils/les enfants → **-ent / écrivent / ont**。
9. **拼字慢一點**:aime、avez、levons、elles、étage、salle de bain。
